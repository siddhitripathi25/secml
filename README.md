# SecML

> **AI/ML-Powered Behavioral Security Analyzer for the Terminal**

SecML is a terminal-based security tool that analyzes system behavior to identify potentially suspicious or anomalous activity using **rule-based detection and machine learning**.

## Features

* 🖥️ Process analysis
* 🌐 Network activity analysis
* ⚙️ System behavior monitoring
* 🤖 ML-based anomaly detection
* 🛡️ Risk scoring
* 📊 Terminal-based security reports

## Tech Stack

* Python
* Typer & Rich
* psutil
* Scikit-learn
* Pytest

## Usage

```bash
secml scan
secml processes
secml network
secml baseline
secml monitor
```
